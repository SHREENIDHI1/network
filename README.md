# RailMPLS Lab — Narrated Course (v2)

**Networking & IP-MPLS: the complete narrated course** — about 3 h 39 min.
Created by **Shreenidhi Sharma · JE (Tele), North Western Railway**.

Is version mein naya kya hai (pichhle 3-hour video ke comparison mein):

- **Awaaz (voice narration)** har slide par — simple English mein, dheere aur saaf (offline text-to-speech voice).
- **Subtitles** neeche hamesha — jo bola ja raha hai wahi likha hua.
- **"Saar" box** — har slide ka Hinglish summary.
- Har chapter: *What you will learn* → concept → railway analogy → diagram (packet hop-by-hop) → **LIVE demo** (asli RailMPLS Lab software ke screenshots) → **Quick check quiz** (6 second sochne ka time) → **Recap**.
- Upar **chapter naam, clock aur progress bar** — pata rehta hai kitna dekha, kitna baaki.
- Shuru mein **Course map** (har chapter ka start time). Wahi list `CHAPTERS.txt` mein bhi hai.
- Naya chapter: **BFD** (v1.1.0), aur poora **software tour** + **troubleshooting method** + **final revision exam**.

## Download aur join kaise karein (Windows)

1. Is branch ke saare `RailMPLS-Narrated-partNN.ts` files aur `JOIN-VIDEO.bat` ek hi folder mein download karo
   (har file kholo → **Download raw file** button).
2. `JOIN-VIDEO.bat` par double-click karo → `RailMPLS-Lab-Narrated-Course.ts` ban jayegi.
3. VLC ya Windows Media Player se chalao. Har part akela bhi chal sakta hai.

Linux / Mac: `sh join-video.sh`
