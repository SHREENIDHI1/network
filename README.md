# RailMPLS Lab — full course video

**Length:** 2 h 57 min · 1920×1080 · 6 parts (~30 min each, 470 MB total)
**Created by:** Shreenidhi Sharma · JE (Tele), NWR

GitHub ek file mein 100 MB se zyada nahi leta, isliye video 6 tukdon mein hai. Har tukda akela bhi chalta hai.

## Download aur ek video banana (Windows)
1. Upar list mein har file par click karo → right side **Download** (⬇) button dabao:
   `RailMPLS-Full-Course-part1.ts` … `part6.ts` aur `JOIN-VIDEO.bat`
2. Saari 7 files ek hi folder mein rakho.
3. `JOIN-VIDEO.bat` par double-click → **RailMPLS-Lab-Full-Course.ts** ban jaayegi = poori 3 ghante ki ek video.
4. VLC ya Windows Media Player mein kholo.

Phone par: har part seedha VLC app mein chala sakte ho (part1 → part6 order mein).
Mac / Linux: `cat RailMPLS-Full-Course-part*.ts > RailMPLS-Lab-Full-Course.ts`
