# RailMPLS Lab — ALL MPLS videos in ONE (6 h 41 min)

Created by **Shreenidhi Sharma · JE (Tele), North Western Railway**.

Saare MPLS videos programmatically ek hi video mein compile kiye gaye hain, beech mein title cards ke saath:

| Time | Part |
|---|---|
| 0:00:00 | Title card |
| 0:00:12 | **Part 1 — Teaser** (3 min 48 s) |
| 0:04:06 | **Part 2 — Narrated course** with voice, subtitles, live demos (3 h 39 min) |
| 3:43:07 | **Part 3 — Deep course + every lab solved** + capstones + quizzes (2 h 58 min) |

Purana 2-hour course aur 16-min course Part 3 mein pehle se shamil hain, isliye unhe dobara nahi joda (duplicate content nahi).

## Ek video kaise banaye (Windows)

1. Saare `RailMPLS-ALL-partNN.ts` aur `JOIN-VIDEO.bat` ek folder mein download karo (har file → **Download raw file**).
2. `JOIN-VIDEO.bat` par double-click → `RailMPLS-Lab-ALL-MPLS-Videos.ts` (ek single 6h41m video) ban jayegi.
3. VLC / Windows Media Player mein chalao.

GitHub 100 MB se badi file allow nahi karta, isliye video parts mein hai — join karne par bilkul ek hi video.
Linux / Mac: `sh join-video.sh`
